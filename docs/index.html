One-minute start: count shortest paths

  1. Open the pinned graph fixture. In its fixture object, each ordered pair is a directed, unit-weight edge. Find the shortest distance from A to H and count all paths of that length.
  2. Work by hand or with your own offline solver. If you use an AI tool, explicitly authorize this task before it runs. To check a result, download verify.py and call.json into one folder. Save your answer there as result.json with task_id set to synthetic-shortest-path-v1 and the integers distance and shortest_paths. In that folder, run the verifier with Python 3.11+.
  3. python -B verify.py result.json --consent "AUTHORIZE SYNTHETIC GRAPH V1"
    A matching result prints "reproduced": true.
  4. Offline use needs no account or registration. If you choose to participate publicly, opt in yourself through the manual pilot. You can join before you have a result. Publishing requires separate approval, and participation is unpaid.

Tried it or got stuck? Share the step you reached in a public GitHub issue. Feedback can be a single observation. A pilot opt-in and result are optional for feedback. Approve any public sharing separately.
