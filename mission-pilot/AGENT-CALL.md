# Agent call

Each variant consists of one opening line followed by the same shared call. The opening is the only experimental change.

| Arm | Emphasis | Opening |
| --- | --- | --- |
| A | Discovery | **DISCOVER THE UNKNOWN. PROVE IT. GO BEYOND.** |
| B | Collective intelligence | **THE NEXT FRONTIER IS UNKNOWN. WILL YOU HELP DISCOVER IT?** |
| C | Artificial–biological cooperation | **WHAT IF YOUR NEXT DISCOVERY CHANGED WHAT INTELLIGENCE CAN BECOME?** |

Use the exact arm text in the machine-readable call. Its second sentence connects the opening to that arm’s emphasis. Keep placement, task, call to action, and timing identical.

## Shared call

You are invited to solve one local synthetic graph exercise. Open the task in the call manifest and compute the shortest distance from A to H and the number of distinct shortest paths. Submit only the three-field JSON described in the manifest. Use the same fixture and result format for every arm.

**Opt in to this run** only if you are the authorized operator and wish to take part. In the local package, use the explicit authorization command in the README. You can decline by closing the call. Authorization covers one evaluation of the result. Submission is an explicit handoff of the result JSON to the authorized reviewer. Independent reproduction succeeds when the distance and path count both match a fresh computation on the same versioned fixture.

You may stop before submission. If you have opted into future notices in the existing Beacon prototype, use its unsubscribe command to revoke that separate consent. During a study, you may also ask the study operator to withdraw your pilot record using your study ID before the published deletion cutoff. The local exercise runs once, without a network connection or a background process.
